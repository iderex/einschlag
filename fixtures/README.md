# Test material

The third part of the layout. Input files a test reads, and the expected output
it is compared against, live here rather than beside the code, so that the same
file can be read by a unit test, by an end-to-end run and by a person checking
the tool by hand.

The directory is empty of material today. The test layout that reads it is issue
#23, the first inputs arrive with the parser in #33, and the worked example in
#68 is the one an operator is meant to be able to run.

Nothing here is real case material. Whether real case material may ever enter
this repository is an open maintainer decision, entry 4 on issue #1, and until it
is answered the answer is no.
